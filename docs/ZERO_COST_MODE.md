# Zero-Cost Mode

Acme Jobs runs with **$0 mandatory recurring cost**. AI and job search use
free tiers by default; nothing paid is required, and every free-tier limit is
guarded so a busy day cannot turn into a bill.

## The rule

No core user-facing workflow may require a paid service. When a free provider
is unconfigured, rate-limited or down, the product **says so** and offers the
next option — it never silently degrades.

| Concern              | Zero-cost default                                 | Optional                 |
| -------------------- | ------------------------------------------------- | ------------------------ |
| AI                   | Gemini free tier → OpenRouter free model (server) | User's own key (BYOK)    |
| AI fallback          | Manual Mode, as an explicit secondary button      | —                        |
| Job search           | 8 keyless sources + company career boards         | Free-key sources (below) |
| Queue                | `PostgresJobQueue`                                | None needed              |
| Auth                 | Argon2id + DB sessions                            | None needed              |
| File storage         | Local filesystem                                  | S3-compatible            |
| Email                | In-app notifications                              | SMTP                     |
| Billing/entitlements | `ManualAdminEntitlementProvider`                  | Whop webhook             |
| Rate limiting        | Database                                          | None needed              |

## AI: on by default, for every plan

Every AI workflow (resume tailoring, mock interview, job search planning and
ranking, cover letters, …) runs on the **server's** keys for free and paid
users alike. The chain is:

1. **Gemini** (`GEMINI_API_KEY`, free at <https://aistudio.google.com/apikey>,
   model `GEMINI_MODEL`, default `gemini-3.5-flash-lite`).
2. **OpenRouter** free model (`OPENROUTER_API_KEY`, <https://openrouter.ai/keys>,
   model `OPENROUTER_MODEL`, default `openrouter/free`).
3. The **user's own key**, if they added one in Settings (BYOK).

A circuit breaker skips a provider that keeps failing. If the whole chain fails
the user sees "AI is unavailable — every provider failed (GEMINI: RATE_LIMIT, …)"
and a **Use manual mode** button. Every result shows which AI produced it
("Generated by Gemini" / "Manual").

**Free-tier limits (verified October 2026):**

| Provider        | Free limit                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Gemini          | Per-project limits are now shown only in AI Studio (<https://aistudio.google.com/rate-limit>). Reports put Flash models at roughly 5–15 RPM and ~20 requests/day. Expect 429s. |
| OpenRouter free | 20 requests/minute; 50 requests/day without credits, 1,000/day after buying ≥ 10 credits once.                                                                                 |

These are small. A mock interview uses one AI call per answer plus one to plan;
a job search uses two (plan + rank). For more than a handful of daily users,
buy OpenRouter credits once, or add a paid Gemini tier — no code change needed.

### Abuse limits instead of paywalls

| Cap (per user, per UTC day) | Free | Paid | Env                                       |
| --------------------------- | ---- | ---- | ----------------------------------------- |
| Resume tailoring runs       | 5    | 30   | `TAILOR_DAILY_CAP_FREE` / `_PAID`         |
| Mock interview sessions     | 3    | 20   | `INTERVIEW_DAILY_CAP_FREE` / `_PAID`      |
| Fresh job searches          | 10   | 40   | `JOB_REFRESH_DAILY_CAP_FREE` / `_PAID`    |
| Any AI action (hourly)      | 30   | 30   | `RATE_LIMITS.aiAssist` in `rate-limit.ts` |

Manual Mode round trips do not count toward the AI caps (they cost nothing).

## Manual Mode: always available, never the default

Manual Mode is a small "Use manual mode (copy prompt → paste answer)" link on
every AI action, and the button offered when AI fails. The pasted answer goes
through exactly the same validation as an API response — schema, evidence
check, and the tailoring fact guard.

## Job search sources

The search agent (`src/jobs/agent.ts`) asks the AI for 4–8 diverse queries from
the user's CV, fans out to every source below in parallel (each with its own
timeout, retry and health status shown in the UI), deduplicates, applies the
location preference, and has the AI re-rank the top ~60 with a one-line
"why this fits". Without AI it still runs, using rule-based queries and ranking.

### Keyless (on by default)

| Source                     | Notes and terms                                                                                                                  |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Arbeitnow                  | One public feed, no server-side search; filtered locally. Cached 15 min.                                                         |
| RemoteOK                   | Must credit Remote OK with a followed link to the listing (we link the listing page).                                            |
| Remotive                   | Asks for **at most ~4 calls/day**: cached 6 h. Jobs are delayed 24 h. Link back + credit required.                               |
| Himalayas                  | Search endpoint, 20 rows/page; credit + link required. Returns 429 if hammered.                                                  |
| Jobicy                     | `tag` search, last 7 days only; poll at most hourly (cached 1 h). Credit + link required.                                        |
| We Work Remotely           | Public RSS (`remote-jobs.rss`), cached 1 h.                                                                                      |
| HN "Who is hiring?"        | Algolia HN API; latest thread, cached 6 h. Roles parsed from each top-level post.                                                |
| The Muse                   | Location-filtered; **currently returns HTTP 403 to server requests** — shown as an error in the health strip.                    |
| Greenhouse / Lever / Ashby | Public career-board JSON for 54 verified companies (`src/jobs/sources/ats.ts`); the AI picks those that fit the target industry. |

### LinkedIn, Glassdoor, Indeed

None of them offers a job-search API to a small third-party app (LinkedIn is
partner-only, Glassdoor closed its API, Indeed retired its Publisher API), and
scraping them breaks their terms. Acme Jobs does not scrape. Their listings
arrive through Google Jobs (SerpAPI) and JSearch, labelled "via LinkedIn" etc.,
and the Jobs page has **Search on LinkedIn / Glassdoor / Indeed** buttons that
open those sites with the query and location prefilled.

### API changes found while building this (October 2026)

- **SerpAPI** discontinued `start`; pagination is `next_page_token` now. The
  free plan is 250 searches/month (was 100).
- **JSearch** moved to OpenWeb Ninja: `GET /jsearch/search-v2`, `x-api-key`
  header, `data.jobs[]`, cursor pagination. The RapidAPI host still works as a
  fallback (`RAPIDAPI_KEY`).
- **Jooble** free keys are 500 requests total, not per month.
- **Remotive**'s free feed is small (17 jobs at test time), delayed 24 h, and
  ignores `search`/`limit`.
- **Arbeitnow** ignores `?search=`.
- **Himalayas** added cursor pagination (Aug 2026); max 20 rows per request.
- **Jobicy** returns only the last 7 days and uses cursors.
- **The Muse** blocks server-side requests with HTTP 403.
- **Gemini** free models are the 3.x Flash family; per-model free limits are no
  longer published in the docs.

## Reading an uploaded job description

TXT, MD, PDF and DOCX uploads are parsed on your own machine by the background
worker. A pasted public job link is fetched server-side with SSRF protection
(http/https only, public addresses only, 8 s timeout, 1.5 MB cap). LinkedIn and
Indeed block automated reading — paste the text for those.

## Keys and secrets

Keys are read from the environment (or `.env`), passed through Docker Compose,
and never written to files, logs or the browser. Provider error messages are
redacted before they are shown. The Gemini key travels in the
`x-goog-api-key` header, not the URL. User BYOK keys are encrypted at rest with
`KEY_ENCRYPTION_SECRET`.

## What a hosted deployment changes

A hosted deployment needs a machine and a database, which is an unavoidable fixed
cost. Everything else stays optional: the stack is PostgreSQL plus one Node
process plus one worker.
